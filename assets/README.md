Approved personal avatar for kno-raziel: the original Vagancia eye inside a red and ivory diamond ribbon. The ribbon uses the thinner version selected on October 22, 2026.

- [SVG master](kno-raziel-avatar.svg): editable vectors on black paper.

- [PNG](kno-raziel-avatar.png): lossless 1024 × 1024 export for the GitHub avatar.

Palette: red `#F02D2A`, ivory `#E6E3DF`, black paper `#080808`. The eye retains the Vagancia Fitness vector paths; the surrounding ribbon follows the reference supplied by the profile owner. Both the eye and the ribbon remain inside the circular avatar crop.
